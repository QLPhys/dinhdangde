# Định dạng đề thi · QL Physics

Công cụ định dạng đề thi Vật lí (Tổ Vật lí · Trường THPT Chu Văn An): đề thô vào, bản Giáo viên và bản Học sinh ra. Chạy hoàn toàn trong trình duyệt, file đề không gửi đi đâu.

- Trang chính: https://qlphys.github.io/dinhdangde/
- `chinh-thuc/` — bản Chính thức, dùng chung cho cả tổ
- `thu-nghiem/` — bản Thử nghiệm, kiểm tra trước khi phát hành
- `phien-ban/` — lưu các bản đã phát hành
- `taode/` — công cụ Kiểm tra ngân hàng và tạo đề thi (một bản duy nhất, cũng là file offline): https://qlphys.github.io/dinhdangde/taode/
